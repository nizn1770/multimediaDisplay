PI TV DISPLAY - GOOGLE SERVICE ACCOUNT SETUP (about 10 minutes)

1. Create a project
   Go to https://console.cloud.google.com, click the project picker (top bar) > New Project.
   Name it e.g. "pi-tv-display" > Create, then make sure it is selected.

2. Turn on the two APIs
   APIs & Services > Library. Search "Google Drive API" > Enable.
   Back to Library, search "Google Calendar API" > Enable.

3. Create the service account
   IAM & Admin > Service Accounts > + Create Service Account.
   Name: "pitv" > Create and continue > skip roles > Done.
   Copy its email (looks like pitv@<project>.iam.gserviceaccount.com).

4. Download the key
   Click the service account > Keys tab > Add key > Create new key > JSON > Create.
   A .json file downloads. Treat it like a password: don't email it, don't put it in GitHub.

5. Put the key on the Pi
   From your computer:
     ssh pi@pitv.local 'mkdir -p ~/pi-tv-display/secrets'
     scp ~/Downloads/<key-file>.json pi@pitv.local:~/pi-tv-display/secrets/service-account.json
     ssh pi@pitv.local 'chmod 600 ~/pi-tv-display/secrets/service-account.json'

6. Share the photo folder
   In Google Drive, right-click the photo folder > Share > paste the service-account email >
   role Viewer > untick "Notify" > Share.

7. Share the calendar and find its ID
   Google Calendar (web) > hover the calendar on the left > three dots > Settings and sharing.
   "Share with specific people" > Add people > paste the service-account email >
   permission "See all event details" > Send.
   Scroll to "Integrate calendar" and copy the "Calendar ID"
   (your main calendar's ID is your Gmail address; others end in @group.calendar.google.com).

8. Configure the Pi (local file only, never committed)
   ssh pi@pitv.local, then edit ~/pi-tv-display/config.local.yaml:
     mock: false
     drive:
       folder_id: "<folder ID - the part after /folders/ in the folder's URL>"
     calendar:
       calendars:
         - id: "<calendar ID from step 7>"
           name: Family
           color: "#4a90e2"
     credentials:
       type: service_account
       service_account_file: /home/pi/pi-tv-display/secrets/service-account.json
   Then: sudo systemctl restart pitv

Add more calendars by sharing each one (step 7) and adding another "- id:" entry.
